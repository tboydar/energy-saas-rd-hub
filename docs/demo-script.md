## 還有 1 分鐘的話

- 切換角色：右上角改成「工程師」，選單少了團隊管理與跨部門協作，Kanban 只能拖自己的卡。改成「PM／CS」只能提需求、看事件狀態。到「權限矩陣」可以看整張表，管理員能直接勾選修改。
- 技術治理：ADR 記錄每個決策的背景與替代方案。CI/CD 流程圖會走一次測試失敗、重跑、等待核准、上線。
- OKR 對齊圖：左到右是專案、路線圖項目、目標。研發主管可以拉線改對齊關係。
- 英文：右上角按 EN，介面和假資料都有英文版。

## 可能被問到

**資料是真的嗎？**
都是虛構的，由固定 seed 的亂數產生器產生，每次重設結果相同。

**AI 功能有呼叫 LLM 嗎？**
沒有。週報與回饋草稿用規則和範本組成，異常偵測用 z-score（連續 2 筆超過 3 個標準差才告警）。所以這個 Demo 不需要 API 金鑰，輸出也能重現。

**為什麼沒用前端框架？**
介面是原生 TypeScript，首屏的 JavaScript 約 50 KB（gzip）。流程圖用 xyflow（React Flow），進到有流程圖的頁面才下載。
