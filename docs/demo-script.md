## 如果還有 1 分鐘

- **切換角色**：右上角改成「工程師」，選單少了團隊管理與跨部門協作，Kanban 只能拖自己的卡；改成「PM／CS」，只能提需求、看事件狀態。再到「權限矩陣」看整張 RBAC 表（管理員可以直接勾選修改）。
- **技術治理**：ADR 記錄決策的背景與替代方案；CI/CD 流程圖示範「測試失敗 → 重跑 → 等待核准 → 上線」。
- **OKR 對齊圖**：專案 → 路線圖 → 目標；研發主管可以直接拉線改變對齊關係。
- **切換英文**：右上角 EN，介面與假資料都有英文版。

## 常被問到的問題

- **資料是真的嗎？** 不是。所有公司、客戶、成員與數字都是虛構的，由固定 seed 的亂數產生器產生。
- **AI 功能有呼叫 LLM 嗎？** 沒有。週報與回饋草稿是規則加範本；異常偵測是 z-score（連續 2 筆超過 3 個標準差才告警）。這樣 Demo 不需要 API 金鑰，輸出也可重現。
- **為什麼不用前端框架？** 介面是原生 TypeScript，首屏只有約 50 KB（gzip）；只有流程圖用 xyflow（React Flow），以延遲載入的方式嵌入。
